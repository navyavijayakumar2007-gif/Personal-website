# Navya T - Portfolio Website

A modern, responsive, dark-themed personal portfolio website built for **Navya T**, a Computer Science and Engineering student at **Jawaharlal College of Engineering and Technology**. 

This portfolio showcases technical skills, academic background, featured projects, and interactive features including a live interactive web calculator demo and direct resume viewing.

---

## 🌟 Key Features

* **Glassmorphism UI/UX:** Styled with dark mode glassmorphism, smooth animations, dynamic mesh gradient background, and custom tailwind styling.
* **Interactive Dynamic Subtitle:** Real-time typewriter text animation in the hero section.
* **Filterable Skills Section:** Skill card display with proficiency bars filtered across categories (`Languages`, `Web Dev`).
* **Live Mini-Calculator Modal:** Fully functional evaluation calculator with history tracking and keyboard event listeners embedded directly inside a popup modal.
* **Resume Preview Modal:** Interactive full-screen preview modal displaying formatted resume details with action buttons.
* **Quick Contact & Toast System:** Interactive clipboard copy buttons for contact information with toast feedback notifications and a validated message contact form.
* **Fully Responsive:** Smooth layout transitions across mobile, tablet, and desktop viewports.

---

## 🚀 Tech Stack

- **HTML5:** Semantic structural layout.
- **Tailwind CSS (CDN):** Utility-first styling framework with dynamic theme configs.
- **JavaScript (ES6+):** Vanilla JavaScript for UI state handling, filter logic, key listening, and modal systems.
- **Font Awesome 6:** Vector icon library.
- **Google Fonts:** Inter & JetBrains Mono typography.
